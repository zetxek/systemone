# Theme images

The [Hugo Themes Showcase](https://themes.gohugo.io/) requires two images in
this directory before submission:

| File | Exact dimensions | Purpose |
|---|---|---|
| `screenshot.png` | 1500 × 1000 | Full-size preview shown on the theme's showcase page |
| `tn.png` | 900 × 600 | Thumbnail shown in the showcase grid |

Both should be real captures of the theme in use (e.g. the home page from
`exampleSite`), not placeholder or stock artwork, cropped/scaled to the exact
pixel dimensions above. Neither file is committed here — this directory only
documents the requirement so the images can be dropped in before the
showcase submission without guessing the spec.
